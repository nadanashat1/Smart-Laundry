# Smart Laundry - Frontend

Team internship project at DevOra (2026).

A React + TypeScript + Vite web app for a laundry service. It has an admin dashboard (orders, services, items, analysis) and a customer side (services, orders, tracking, profile, addresses).

## My part

The admin delivery pages, plus the customers management and customer details pages.

## Team

Built with a team; shared with the company's permission.

## Run

```
npm install
npm run dev
```
